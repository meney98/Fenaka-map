Fenaka Fonadhoo Interactive Map

Features:
- Colored zones
- Clickable building shapes
- Popup zone name
- House name / number
- Distribution Box Number
- Breaker Number
- Owner Name
- Mobile Number
- Additional popup information
- Zoom and pan controls
- Search across house/place, zone, DB number, breaker number, owner and mobile

IMPORTANT: The uploaded map PDF supplies place/house labels, but it does not supply distribution-box numbers, breaker numbers, owner names or mobile numbers. Those fields therefore show “Not entered” until real data is added to script.js.
