FENAKA FONADHOO INTERACTIVE MAP

Open index.html in a browser, or upload all files in this folder to GitHub Pages.

Current setup:
- Clean WAMCO PDF is used as the base map.
- No feeder boundary lines are displayed.
- Controls: Fenaka Branch Feeder, SS01-SS07.
- SS06 and SS07 intentionally have no houses.
- SS02 currently includes the six houses explicitly supplied: Maza, Hiyaalee, Keveli, Sunset, Meylaa, Tharividhaage.
- Red/green status is stored locally in the browser.
- Customer information is not exposed publicly.

IMPORTANT: The remaining SS01/SS03/SS04/SS05/Fenaka house assignments need to be entered after their exact membership is confirmed from the drawn feeder reference. Secure owner-only customer data requires a backend/login; do not put private customer data directly in app.js.
