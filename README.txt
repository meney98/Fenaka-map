FENAKA AREA MARKER

1. Open index.html.
2. Select SS1, SS2, SS3 or SS4.
3. Tap points around that electricity distribution area.
4. Tap FINISH AREA.
5. Repeat for all areas.
6. Tap SAVE AREAS. Your phone/browser saves fenaka-areas.json.
7. Send fenaka-areas.json back to ChatGPT.

This tool does not alter the underlying Fenaka map image.
